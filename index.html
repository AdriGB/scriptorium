Acerca de Scriptorium

Editor local y offline-first para tarjetas de personaje.

  • Version 1.2.3
    Interfaz, exportacion y cache sincronizados.
  • Compatible con CharaCardV2
    Importa y exporta tarjetas JSON y PNG con metadatos.
  • Procesamiento local
    Las cartas y la boveda permanecen en este dispositivo.
  • Traduccion opcional
    Solo el texto que elijas traducir se envia a Google Translate.
  • Aplicacion instalable
    Compatible con PWA, uso offline y atajos de teclado.
